# Documentation map

Welcome to the ATSCheck Desktop documentation. Start with the guide that
matches what you need to do:

## Use ATSCheck Desktop

1. [Install ATSCheck Desktop](SETUP.md) — download and install the app, connect
   an optional model provider, understand local data, and troubleshoot launch.
2. [Follow the user guide](USER_GUIDE.md) — work through resume upload,
   resume building, cover letters, job tracking, and optional analysis.
3. [Configure features](feature-flags.md) — control optional feature groups
   with environment variables.

## Build and contribute

- [Build and run from source](DEVELOPMENT.md) — tools, dependencies,
  development startup, tests, and desktop packaging.
- [Contributing](../CONTRIBUTING.md) — code and documentation standards,
  validation expectations, and pull requests.
- [Code of Conduct](../CODE_OF_CONDUCT.md) — community expectations and
  private reporting.
- [Security and privacy](../SECURITY.md) — data boundaries and responsible
  vulnerability reporting.

## Publish a release

[Release process](RELEASES.md) documents the current installer set and the
maintainer checklist for building, testing, and publishing future releases.
