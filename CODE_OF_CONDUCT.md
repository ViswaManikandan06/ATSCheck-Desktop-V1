# Community Code of Conduct

ATSCheck Desktop is a community project. We want project spaces to be welcoming,
constructive, and safe for people with different backgrounds and levels of
experience.

## Our standards

Examples of behavior that support a healthy community include:

- Treating people with respect and patience.
- Discussing ideas, evidence, and code without attacking contributors.
- Giving and receiving constructive feedback in good faith.
- Making room for different perspectives and experience levels.
- Protecting personal information shared with the project.

Examples of unacceptable behavior include:

- Harassment, discrimination, intimidation, or targeted personal attacks.
- Publishing another person's private information without permission.
- Sharing resumes, API keys, credentials, or other sensitive material without
  authorization.
- Deliberately disrupting project discussions or repeatedly acting in bad faith.
- Retaliating against someone for raising a concern in good faith.

## Scope

This code applies in project-managed spaces, including issues, pull requests,
discussions, and project communication. It also applies when someone is
representing the project in public.

## Reporting a concern

If you experience or witness unacceptable behavior, contact the project
maintainers privately through the maintainer contact information on the
[GitHub profile](https://github.com/ViswaManikandan06). Do not post private
personal information in a public issue.

When reporting, include the relevant project space, a description of what
happened, and any context that can be shared safely. Avoid attaching private
resumes, credentials, or unrelated personal data.

## Maintainer response

Maintainers will review reports as promptly as possible, respect the privacy
of those involved, and take action they consider appropriate. Possible actions
include a request to stop, removal of harmful content, a temporary restriction,
or removal from project spaces. Retaliation for making a good-faith report is
not acceptable.

## A note on enforcement

Maintainers are expected to apply these standards consistently and to explain
enforcement decisions when doing so can be done without exposing private
information.
